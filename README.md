# Hop Diffusion Lab

그래프 신경망(GNN)의 **message passing**을 직접 실행해 보면서, k-hop 정보 전파(reachability)와
**over-smoothing** 현상을 동시에 관찰할 수 있는 인터랙티브 시각화입니다. 순수 HTML/CSS/JS로만
작성되어 있어 별도 빌드나 서버 없이 브라우저에서 바로 열립니다.

## 이 실험이 보여주는 것

36개의 노드가 3개의 클러스터(각 12개)로 나뉘어 있고, 클러스터 사이는 4개의 다리(bridge) 엣지로만
연결되어 있습니다. 매 hop `k`마다 모든 노드는 **자기 자신과 이웃의 값을 평균**내어 갱신합니다 —
self-loop가 있는 평균 message passing과 동일한 규칙입니다.

```
h_v^(k+1) = ( h_v^(k) + Σ_{u∈N(v)} h_u^(k) ) / (1 + deg(v))
```

이 규칙을 반복하면 두 가지 현상이 동시에 나타납니다.

- **Reachability (도달 범위)**: `h_v^(k)`는 v로부터 k-hop 이내에 있는 노드들의 초기값에 의해서만
  결정됩니다. 그래프의 지름(대개 5~6 hop) 정도만 지나도 정보가 전체 그래프에 도달합니다.
- **Over-smoothing (과도한 평활화)**: 하지만 k를 지름보다 훨씬 크게 늘리면, 원래 뚜렷이 구분되던
  3개 클러스터의 값이 그래프 전체의 (연결 구조로 가중된) 평균 하나로 수렴하며 서로 구별할 수 없게
  됩니다.

"정보 다양성 유지율"은 특징 벡터의 분산을 k=0 대비 백분율로 표시한 값입니다 (Fisher information이
아니라 단순 통계 분산 — GNN 논문에서 흔히 쓰는 Dirichlet energy와 사실상 같은 양입니다):

```
Var(k) = (1/N) Σ_v ‖h_v^(k) − mean(H^(k))‖²
```

이 분산은 **클러스터 내부(within-cluster)** 와 **클러스터 간(between-cluster)** 로 정확히 분해됩니다
(ANOVA 분해). 클러스터 내부 차이는 몇 hop 만에 빠르게 사라지지만, 클러스터를 잇는 다리 엣지가 몇 개
안 되기 때문에 클러스터 간 차이는 훨씬 느리게 사라집니다 — 그래서 어떤 그래프에서는 hop을 꽤 반복해도
클러스터가 한동안 뚜렷이 구분되어 보입니다. 갱신 행렬 `P = D⁻¹(A+I)`는 연결된 그래프 위의 비주기적
확률 행렬이라, Perron-Frobenius 정리에 의해 k→∞에서는 결국 모든 노드가 정확히 하나의 값으로
수렴합니다 — 다만 그 속도가 그래프의 스펙트럴 갭(다리 엣지 수와 직결)에 좌우될 뿐입니다.

## 기능

- **더블 윈도우 그래프**: 같은 그래프를 두 개 나란히 두고 왼쪽엔 특징값 색상(Over-smoothing), 오른쪽엔
  도달 범위 색상(Reachability)을 모드 전환 없이 동시에 보여줍니다. 왼쪽은 파란색 한 톤의 명도로 특징값의
  크기를 표현하고(초기값의 10~90 백분위 구간에 맞춰 대비를 강조), 오른쪽은 선택한 시작 노드로부터 몇
  hop 만에 각 노드에 정보가 도달하는지 색과 노드 오라(글로우)로 함께 보여줍니다. 두 그래프 중 어느 쪽
  노드를 클릭해도 시작 노드가 바뀌고, 아래 결과 차트가 함께 갱신됩니다.
- **노드 오라 (도달 범위 그래프에 내장)**: 시작 노드를 중심으로 방금 도달한 프런티어는 밝은 글로우,
  이미 정착된 노드는 옅은 글로우로 강조합니다. 각 그래프 아래에는 노드별 값/도달 시점을 한 줄 스트립으로
  보여줘서, 왼쪽은 특징값이 색으로 얼마나 뒤섞였는지, 오른쪽은 각 노드가 몇 hop 만에 도달했는지(회색 칸은
  아직 미도달)를 한눈에 비교할 수 있습니다.
- **정보 다양성 / 도달 비율 차트**: k에 따른 두 지표를 나란히 비교해, "정보가 전부 도달한 시점"과
  "그 이후로도 계속 평활화가 진행되는 구간"을 한눈에 볼 수 있습니다. k 범위는 0~180으로, 가장 느리게
  섞이는 랜덤 그래프도 결국 완전히 수렴하는 지점까지 보여줍니다.
- **로그 스케일 토글**: 선형 스케일에서는 1% 이하가 거의 0처럼 보이지만, 로그 스케일로 전환하면 그
  이후로도 지수적으로 계속 감소하는 모습을 직선으로 확인할 수 있습니다.
- **클러스터 내부 vs 클러스터 간 분산 차트**: 전체 분산을 두 성분으로 분해해, 클러스터 내부 차이는
  몇 hop 만에 사라지는 반면 클러스터 간 차이는 훨씬 느리게 사라지는 것을 직접 비교해 보여줍니다.
- 그래프의 노드를 클릭하면 시작 노드를 바꿀 수 있고, "새 그래프로 실험" 버튼으로 시드를 바꿔가며
  같은 현상이 반복되는지 확인할 수 있습니다.
- 라이트/다크 모드를 모두 지원합니다.
