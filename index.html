수식 보기

모든 노드는 매 hop마다 자기 자신과 이웃의 값을 평균 내어 갱신합니다 (self-loop가 있는 평균 message passing):

h_v^(k+1) = ( h_v^(k) + Σ_{u∈N(v)} h_u^(k) ) / (1 + deg(v))

이 규칙을 k번 반복하면 h_v^(k)는 v로부터 k-hop 이내에 있는 모든 노드의 초기값에 의해서만 결정됩니다 — 이것이 "reach" 곡선입니다.

"정보 다양성"은 8차원 특징 벡터 전체의 분산입니다 (Fisher information이 아니라 단순 통계 분산):

Var(k) = (1/N) Σ_v ‖h_v^(k) − mean(H^(k))‖²

노드 벡터들이 평균에서 얼마나 퍼져 있는지를 재는 값으로, GNN 논문에서 over-smoothing을 정량화할 때 쓰는 Dirichlet energy(그래프 라플라시안 이차형식)와 사실상 같은 양입니다. 그래프에 self-loop가 없다면 Var(k)는 정확히 Dirichlet energy와 일치합니다. 화면에는 k=0 값 대비 백분율 Var(k)/Var(0)×100%로 표시해서, 100%(완전히 구별됨)에서 시작해 0%(전부 동일)로 줄어드는 정도를 직관적으로 보여줍니다.

이 평균화는 확률적으로 수렴하는 연산이라, k가 그래프의 지름을 훨씬 넘어서면 모든 노드의 값이 그래프 전체의 (연결 구조로 가중된) 평균 하나로 수렴합니다 — Var(k)가 0에 가까워지는 이유입니다.

노드 36개 · 3개 클러스터(각 12개) · 클러스터 간 다리 엣지 4개 · 노드 특징 벡터 차원 8 · 색상은 특징 벡터를 하나의 스칼라로 투영해 파란색 한 톤의 명도로만 표현합니다 (색상=값의 크기, 위치=클러스터 정체성). 초기(k=0) 값의 10~90 백분위 구간을 색상의 최소~최대로 삼아 대비를 강조했고, 이 구간을 벗어나는 극단값은 양 끝 색으로 고정됩니다 (정확한 값은 노드에 마우스를 올리면 확인 가능). "새 그래프로 실험"을 눌러 시드를 바꿔가며 같은 현상이 반복되는지 확인해 보세요.
