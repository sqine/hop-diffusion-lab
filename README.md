# Hop Diffusion Lab

그래프 신경망(GNN)의 **message passing**을 직접 실행해 보면서, k-hop 정보 전파(reachability)와
**over-smoothing** 현상을 동시에 관찰할 수 있는 인터랙티브 시각화입니다. 순수 HTML/CSS/JS로만
작성되어 있어 별도 빌드나 서버 없이 브라우저에서 바로 열립니다.

## 미리보기

`index.html`을 브라우저로 열면 됩니다. 배포 없이 로컬에서 바로 확인하려면:

```bash
git clone <이 저장소 URL>
cd hop-diffusion-lab
open index.html   # macOS. Windows는 start index.html, Linux는 xdg-open index.html
```

## 이 실험이 보여주는 것

36개의 노드가 3개의 클러스터(각 12개)로 나뉘어 있고, 클러스터 사이는 4개의 다리(bridge) 엣지로만
연결되어 있습니다. 매 hop `k`마다 모든 노드는 **자기 자신과 이웃의 값을 평균**내어 갱신합니다 —
self-loop가 있는 평균 message passing과 동일한 규칙입니다.

```
h_v^(k+1) = ( h_v^(k) + Σ_{u∈N(v)} h_u^(k) ) / (1 + deg(v))
```

이 규칙을 반복하면 두 가지 현상이 동시에 나타납니다.

- **Reachability (도달 범위)**: `h_v^(k)`는 v로부터 k-hop 이내에 있는 노드들의 초기값에 의해서만
  결정됩니다. 그래프의 지름(대개 5~6 hop) 정도만 지나도 정보가 전체 그래프에 도달합니다.
- **Over-smoothing (과도한 평활화)**: 하지만 k를 지름보다 훨씬 크게 늘리면, 원래 뚜렷이 구분되던
  3개 클러스터의 값이 그래프 전체의 (연결 구조로 가중된) 평균 하나로 수렴하며 서로 구별할 수 없게
  됩니다.

"정보 다양성 유지율"은 특징 벡터의 분산을 k=0 대비 백분율로 표시한 값입니다 (Fisher information이
아니라 단순 통계 분산 — GNN 논문에서 흔히 쓰는 Dirichlet energy와 사실상 같은 양입니다):

```
Var(k) = (1/N) Σ_v ‖h_v^(k) − mean(H^(k))‖²
```

## 기능

- **특징값 · Over-smoothing 모드**: 노드 색상(파란색 한 톤의 명도)으로 특징값의 크기를 표현하고,
  k가 커질수록 색이 하나로 수렴하는 과정을 보여줍니다. 색상은 초기값의 10~90 백분위 구간에 맞춰
  대비를 강조합니다.
- **도달 범위 · Reachability 모드**: 선택한 시작 노드로부터 몇 hop 만에 각 노드에 정보가 도달하는지
  색으로 보여줍니다.
- **노드 오라 패널**: 시작 노드를 중심으로 방금 도달한 프런티어는 밝은 글로우, 이미 정착된 노드는
  옅은 글로우로 표시해 정보가 퍼져나가는 모습을 강조합니다.
- **정보 다양성 / 도달 비율 차트**: k에 따른 두 지표를 나란히 비교해, "정보가 전부 도달한 시점"과
  "그 이후로도 계속 평활화가 진행되는 구간"을 한눈에 볼 수 있습니다.
- 그래프의 노드를 클릭하면 시작 노드를 바꿀 수 있고, "새 그래프로 실험" 버튼으로 시드를 바꿔가며
  같은 현상이 반복되는지 확인할 수 있습니다.
- 라이트/다크 모드를 모두 지원합니다.

## 기술 스택

외부 런타임 의존성 없이 순수 HTML + CSS + JS로 작성했습니다 (Google Fonts만 CDN에서 불러옵니다).

- 그래프 레이아웃: Fruchterman-Reingold 스타일의 힘-기반 배치 알고리즘을 직접 구현
- 색상: 파란색 단일 색조(hue)의 명도만으로 값의 크기를 표현하는 sequential 컬러 스케일
- 시드 기반 난수 생성기(mulberry32)로 그래프/특징값을 재현 가능하게 생성

## GitHub Pages로 배포하기

이 저장소를 그대로 GitHub Pages에 올리면 별도 설정 없이 바로 볼 수 있습니다.

1. GitHub에 새 저장소를 만들고 이 폴더 내용을 푸시합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Source**를 `Deploy from a branch`로 설정하고, 브랜치는 `main`, 폴더는 `/ (root)`를 선택합니다.
4. 잠시 후 `https://<사용자명>.github.io/<저장소명>/`에서 바로 확인할 수 있습니다.
